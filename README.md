# PokéQuiz

GBA 风格的初代 151 宝可梦看图答题应用。

- 经典训练 151 题、极速挑战 15 题、进阶训练 50 题。
- 中文 / English 切换，支持中英文名称答题。
- 多轮训练暂停、继续与记录删除。
- 成就徽章、头像、边框与季节装饰收藏。
- 答题页一屏高度适配，答对自动切题，可揭晓答案并滑动回看。

## 运行

纯 HTML5 / CSS / JavaScript，无构建步骤。可通过静态 HTTP 服务运行。GitHub Pages 从 main 分支根目录发布。

玩家档案及训练记录保存在当前浏览器 localStorage；昵称档案是本地演示，不是真实账户认证，不支持跨设备同步。宝可梦图片来自 PokeAPI sprites，字体来自 Google Fonts。

页面：https://ychenw.github.io/pokemon-quiz/
